--перегляньте відео, а далі слідуйте інструкції:

1)Спочатку завантажуєш проєкт з репозиторію та відкриваєш його у своєму VS Code.
2)Перевіряєш, щоб у тебе була встановлена Java 17 (або новіша) та Maven.
3)Заходиш у файл src/main/resources/application.properties і підставляєш туди свої дані від бази даних(тестувалося у Supabase)
4)Відкриваєш термінал у папці проєкту, робиш очищення й збірку командою mvn clean compile.
5)Запускаєш сам застосунок через mvn spring-boot:run і чекаєш, поки в консолі з'явиться повідомлення про успішний старт.
6)Тепер твій сервер працює на http://localhost:8080, а таблички зберігаються в базі даних Supabase.
(для редагування використовуй postman)
